# 圖形關係 UX 檢查與修正

日期：2026-10-15（Asia/Taipei）

## 已確認問題

| 問題 | 影響 | 修正 |
|---|---|---|
| 0 筆沿用「開始探索」初始文案 | 無法判斷已查詢、無資料或失敗 | 篩選區與圖中央明示地區、類型、科別及 0 筆原因 |
| 唯一結果訊息在圖底部 | 容易忽略查詢結果 | 增加上方可見狀態區與無障礙宣告 |
| 無資料時仍叫使用者選院所 | 指引與結果矛盾 | 同步更新右側、清單及工具可用狀態 |
| 空結果沒有下一步 | 使用者需自行猜測調整方式 | 一鍵改查全部院所／取消科別限制，保留地區 |
| 失敗與 0 筆都看似空圖 | 容易誤以為沒有醫療資源 | 分離錯誤與空結果；上方可重試與取消 |
| 變更條件後仍顯示舊圖 | 可能誤認舊圖為新條件結果 | 標示條件未套用、保留舊查詢範圍、關閉舊詳情 |
| 搜尋結果只有隱藏 aria label | 看不到命中數或無命中原因 | 顯示搜尋範圍及命中訊息，提供清除高亮 |
| 高亮後其他節點只剩 16% 不透明度 | 難以保留整體脈絡 | 提高為 40%，可直接清除高亮 |
| 無科別院所顯示不可用「展開科別」 | 不知道為何不能展開 | 按鈕明示尚無科別資料，詳情仍可開啟 |
| 每次載入更多都縮放全圖 | 視角跳動、節點越來越小 | 載入更多保持原視角，由使用者選完整顯示 |

- 手機上的完整關係圖仍受畫面寬度限制；保留縮放、拖曳及完整名稱文字清單，尚未新增全螢幕探索模式。
- 圖形最多 36 間，名稱搜尋只含已載入節點，非全資料庫搜尋；現在會明示範圍。
- 此次為程式狀態與畫面驗證，未進行外部使用者訪談或正式螢幕閱讀器實機測試。
- 未自動擴大行政區或推薦鄰近醫院，避免擅自改變查詢範圍及推論距離。
