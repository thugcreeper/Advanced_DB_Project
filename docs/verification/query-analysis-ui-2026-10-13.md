# 查詢分析 UI/UX 重構驗證

日期：2026-10-13。範圍僅前端、測試及文件；後端Java、API契約、Cypher及Neo4j資料沒有修改。

## 介面層級

初始只呈現縣市與行政區。其他既有條件移入預設收合的「進階篩選」，分為綜合所得、人口與土地、醫療院所、醫療科別與醫事人員四組，各自可展開／收合。
所得分組在進階區展開後預設可見，其餘組預設收合。收合只改UI狀態，條件不會被清除；進階總列及各組顯示已設定條件數。
排序、清除條件、執行篩選固定在表單底部，不藏在進階區中。
scope保持原本「人員／科別統計範圍」語意，沒有將它誤標成影響全區院所總數的類型篩選。
沒有加入現有API不支援的人口密度或醫事人員總計篩選，也沒有刪除任何既有篩選欄位。

## 共用選擇器

`shared/hierarchical-selector.js` 提供同一套單選互動，科別、人員只傳入名稱、表單值與分類定義。
`shared/medical-categories.js` 管理使用者指定的分類順序及名稱，與API實際值交集後呈現；送出的值仍是原始API字串。
`shared/hierarchical-selector.css` 負責彈出層、內部捲動、選取及焦點樣式。

- 科別：常用16、牙醫11、中醫8、其他10，共45種且無重複。
- 人員：常用12、牙醫2、其他13，共27種且無重複。
- 常用預設展開，其餘收合；分類標題可獨立切換，不影響選取。
- 搜尋跨分類，暫時展開有結果的分類；清空搜尋恢復原展開狀態。
- 顯示目前選取，保留不限、清除、Escape及點擊外部關閉。
- ArrowUp／ArrowDown／Home／End可移動選項焦點，Enter／Space選取；分類summary使用原生鍵盤操作。
- 原生Popover使彈出層不被表單容器裁切；依視窗可用空間往上或往下顯示，最大480px並內部捲動。
- API新名稱歸到其他，重複值合併、缺少定義名稱另行提示，原始字串不改寫。差異同時顯示於選擇器下方及console warning。
- 搜尋input不參與查詢條件監聽，不會因搜尋選項而清空結果或觸發查詢。
