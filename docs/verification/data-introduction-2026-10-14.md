# 資料介紹頁實作與來源核對

日期：2026-10-14（Asia/Taipei）。

## 功能

新增 `/pages/data/index.html`，沿用共用藍色樣式與側邊欄。
章節包含資料來源、指標定義、資料結構、使用限制；章節連結可直接定位。
六個來源資料集的官方連結另開分頁並設置 `noopener noreferrer`。
來源欄位包含提供機關、專案採用年度、更新頻率與統計用途。
頁面註明來源頁核對日期不是原始檔下載日期，官方網站更新不會自動更新本站資料。
查詢分析及行政區查詢的「資料介紹」佔位改為可用連結，保留前一輪移除首頁的變更。
圖形關係維持未開放。沒有新增後端 API、修改統計查詢、匯入資料或改 Schema。

## 行政區代碼

使用者確認代碼來自醫院／診所人力與科別 ZIP 的附帶表。
實際下載並唯讀檢查 [114 年醫院人力 ZIP](https://www.mohw.gov.tw/dl-101848-66ebc291-6bba-45b4-85ea-96a5ec2add02.html)。
附帶 CSV 包含：鄉鎮市區碼、101／102 年適用名稱、103 年以後適用名稱。
以「103 年以後適用」欄位對照正式 repo 的 `data/行政區與代碼.csv`：
專案 368 筆、來源 368 筆，代碼與名稱差異 0 筆。例如 102 對應臺北市大安區。
不把本代碼體系當成常見 8 碼戶政代碼，也不額外改寫代碼。

## 院所位置資料

依使用者確認：政府公開資料取得後自行處理，不提供 URL。
頁面按此說明來源，不再要求 URL，也不臆測原始資料集、版本或地理編碼方式。
明確區分院所地圖資料與行政區統計彙總；位置清單不能宣稱是 114 年完整院所名冊或即時營業資料。
先前搜尋的 15393／102011 等相關資料集未被確認為專案來源，因此不列為已採用資料。
