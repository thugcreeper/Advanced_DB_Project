# 全站 UX 審視與 Snackbar 修正

日期：2026-10-15（Asia/Taipei）

## 共通回饋規則

`shared/snackbar.js/.css` 提供固定於視窗上方、最少 16px 字級的高對比提示，不依頁面捲動位置；每次顯示 3000ms，新訊息重設計時。使用 role=status、polite、atomic，文字用 textContent，不搶焦點、不阻擋操作、不使用 alert。pagehide 清除計時器。
通知內沒有必須在三秒內完成的操作；錯誤原因、重試按鈕及空結果說明仍保留於頁面。

## 逐頁審視

| 頁面 | 發現／處理 |
|---|---|
| 圖形關係 | 空結果訊息原先在圖底部且不醒目。現在完成、空結果、失敗、取消均以 snackbar 回饋；保留具體地區／類型說明與調整條件按鈕。成功及初始不再增加重複大型提示列。 |
| 行政區查詢 | 搜尋結果與錯誤可能落在視窗外。加入找到幾間、地區＋類型空結果、失敗及選項載入錯誤的通知；科別選項失敗新增重新載入入口，不清空已選地區。 |
| 統計查詢 | 長表單使表格結果不容易立即被注意。完成、空結果、失敗與 CSV 開始下載有 snackbar；篩選選項初始／縣市載入失敗新增重試按鈕，避免只能重新整理。 |
| Cypher 查詢 | 執行、空結果、拒絕／失敗、空白查詢、複製成功／降級與 CSV 下載都有即時回饋；保留編輯器內詳細狀態。沒有改變唯讀 API 或自動重送語意。 |
| 院所詳情 | 非同步失敗另有 snackbar，面板中保留重試；電話、Google 地圖與鍵盤回復沿用既有行為。 |
| 資料介紹 | 靜態閱讀頁不增加無意義的 toast。檢查來源表格的手機卡片、外部連結另開分頁提示、18px 圖示、側邊導覽、關於對話框及無水平頁面溢出。 |

## Legacy 測試清理

刪除 StatisticsSnapshotTest.java、integration/facilities.test.cjs、verify-snapshots.cjs、example-snapshot.cjs。
從仍在使用的測試檔移除歷史統計固定預期、audit JSON 比對、一次性多科別快照與兩項未實作 fixture TODO。
Cypher 範例保留實際執行／結果契約與識別碼唯一性，移除凍結歷史資料值；目前其他 API、互動、CSV、唯讀及安全測試保留。
測試預設服務埠統一 18080，隔離 stop/start 測試埠維持其專用值。測試 README 已更新，無需舊搬移快照；歷史報告及備份不刪除。

Java 本輪執行 49 案：48 通過、1 Aura opt-in 未啟用略過、0 失敗。已刪除的十項舊快照不再執行，沒有修改資料庫或把舊預期改成目前值。
瀏覽器已驗證桌面 1440px 與手機 390px 在捲到頁底時仍看得到 snackbar，2.6 秒仍顯示、3.15 秒已隱藏；空結果快速恢復、錯誤與空結果區分、跨頁通知及現有 CSV 行為亦有驗證。

## 尚存限制

- 手機關係圖密度仍較高，完整名稱可從清單取得；未新增全螢幕模式。
- snackbar 依要求三秒消失；需要較長閱讀時間者仍可使用頁內說明及重試入口。
- 本次是功能與版面審視，未進行正式使用者訪談或實機螢幕閱讀器研究。
- 新版尚未部署 Render／GitHub Pages，正式環境仍需隨版本發布驗證。
